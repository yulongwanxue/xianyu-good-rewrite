# 闲鱼商品首图生图提示词规范

本文件用于把首图策划转换成可执行的生图提示词。目标是一张首图同时做到：**缩略图能认出商品、画面有一个值得点开的理由、视觉有记忆点、所有内容有事实依据**。这里借鉴参考项目的视觉方法，只服务于一张首图，不生成详情图套装。

## 一、写提示词前先确定五件事

提示词不要从“高级、精致、吸睛”开始。先确定以下内容，再把它们写成画面指令：

1. **商品身份**：教程、资料、模板、软件、源码还是服务。主标题必须让陌生用户看懂这一点。
2. **一个主钩子**：这张图最值得点击的一个理由，例如“内容整理得清楚”“把重复步骤集中处理”“交付成果类型明确”。不要在一张图中平铺多个卖点。
3. **一个主视觉主体**：买家看到的具体对象，例如资料页组合、模板局部、抽象工作区、交付成果示意或输入—处理—交付流程。
4. **一个视觉记忆点**：从商品本身选择强对比、独特材质、清晰流程、主题隐喻或版式动作。记忆点服务于商品，不靠无关炫光制造刺激。
5. **文字预算**：主标题一处，辅助短语最多一处；小角标只有在有明确依据且确实有帮助时才使用。交付、售后和侵权说明通常留在商品描述，不抢首图空间。

内部先写成一句话：

> 这张图用【主视觉主体】表现【一个主钩子】，让【目标买家】在缩略图中立即认出这是【商品身份】。

如果这句话同时塞了两个以上主钩子，应先删减。

## 二、首图吸引力的画面结构

一张有吸引力的首图不等于信息更多。提示词按以下层级安排视觉重量：

1. **第一眼：身份与主体**。商品标题和主视觉应形成一个清楚的识别组合。
2. **第二眼：主钩子**。通过主体的局部放大、流程动作、内容层次或前后关系表达购买理由；不使用无依据的结果数字。
3. **第三眼：质感与可信度**。用网格、纸张、屏幕、卡片、材质、光线和留白建立完成度，但不添加无法证明的截图、徽章或品牌。

可从下面的视觉动作中选一个作为记忆点：

| 视觉动作 | 适合商品 | 做法 | 边界 |
| --- | --- | --- | --- |
| 内容放大 | 资料、模板、教程 | 放大 1–3 个代表性页面或结构卡片 | 没有真实素材时使用抽象示意，不伪造目录和文件数量 |
| 流程聚焦 | 工具、效率服务、技术服务 | 用少量节点表现输入、处理、交付 | 不添加未提供的步骤、平台或效果数字 |
| 成果悬浮 | 设计、排版、制作服务 | 把可交付成果作为画面中心，周围留出标题空间 | 不冒充真实客户案例或历史作品 |
| 主题隐喻 | 课程、知识产品、创作者工具 | 用与主题相关的物件或场景承载商品内容 | 隐喻必须仍能让人看出商品类别，不能变成泛海报 |
| 强结构对比 | 需要快速理解的资料或工具 | 用深浅、大小、疏密或左右关系突出主次 | 不做没有事实依据的“使用前/使用后”承诺 |

### 构图要求

- 选择一个版式骨架：左文右物、右文左物、上标题下主体、中央主体或简化流程。不要在一张图里混用多个骨架。
- 主体占画面显著面积，文字和主体之间有明确的空间关系；背景只负责衬托，不与主体争夺对比度。
- 默认保留 8%–10% 安全边距。主标题、主体和辅助短语都要落在安全区域内。
- 设计应在缩到约 180–240px 宽时仍保留商品身份和主钩子。缩略图看不清时，先删辅助文字、放大主体或提高对比，不要继续堆装饰。
- 采用 2 个主色加 1 个点缀色即可。配色服务商品气质和信息层级，避免无理由的紫色渐变、霓虹光效和玻璃卡片组合。

## 三、含字版 prompt

当下游没有可靠的程序叠字能力时，输出完整的含字版提示词。按以下顺序写成一段具体指令：

1. **成品身份**：一张 1:1、1080×1080 像素的闲鱼商品首图。
2. **商品与人群**：明确商品身份、目标买家和一个主钩子。
3. **主视觉与记忆点**：具体说明主体是什么、放在哪、占多大、用什么视觉动作表达主钩子。
4. **版式层级**：标题区、主体区、辅助短语区的相对位置；说明谁最醒目、谁退到背景。
5. **准确文字**：明确“图片中只允许出现以下文字”，逐字列出主标题和辅助短语；禁止模型自行增加说明、数字、英文或装饰字。
6. **视觉语言**：配色、材质、光线、空间、边缘处理和商业气质。用可观察的画面词，不只写形容词。
7. **事实边界**：没有真实素材时，要求内容为概念示意，不冒充真实软件界面、课程后台、客户案例、评价、证书或收益截图。
8. **缩略图目标**：明确要求手机列表缩小后仍看懂商品类别和主钩子。

可使用下面的句式骨架，替换所有占位内容：

> 制作一张 1:1 正方形、1080×1080 像素的中文闲鱼商品首图。商品是【商品身份】，面向【目标买家】，这张图只突出一个主钩子：【主钩子】。采用【版式骨架】，让【主视觉主体】位于【具体位置】并占画面约【比例】，通过【一个视觉动作/记忆点】表现主钩子；【标题区】保持清楚留白，背景使用【具体背景和材质】，不抢主体对比度。画面只允许出现以下准确文字：主标题「【商品身份标题】」；辅助短语「【可信短语】」；不得出现其他中文、英文、数字、伪文字、乱码、LOGO、二维码或水印。使用【主色】、【辅色】和【点缀色】，建立明确的前后层级与 8%–10% 安全边距。没有真实商品素材的部分只能做概念示意，不得伪造软件截图、课程目录、客户案例、评价、证书或收益证明。画面缩小到手机列表缩略图后，仍应一眼看出卖的是什么以及为什么值得点开。

不要把完整商品描述、交付条款或侵权声明放进提示词。它们属于商品文案；首图只保留有助于识别和点击的短表达。

## 四、无字背景版 prompt

如果下游能用 HTML、Pillow 或其他程序叠字，优先生成无字背景，再独立叠加中文。无字版必须与含字版保持同一个商品、主钩子、主体、构图和配色，只移除文字。

无字版至少写清：

- 文字留白区的具体位置和比例，不能只说“留白”；
- 主体的具体形状、材质、层叠关系和视觉重心；
- 所有卡片、屏幕和页面只使用抽象块、线条、几何图形，不出现可读内容；
- 画面完全不出现中文、英文、字母、数字、伪文字、乱码、LOGO、二维码或水印；
- 背景仍然有商品感和视觉记忆点，不能退化成空白渐变。

建议写法：

> 制作一张 1:1、1080×1080 像素的【商品身份】首图无字背景。延续【主钩子】和【版式骨架】，在【位置】预留约【比例】的干净文字区；在【位置】放置占画面约【比例】的【主视觉主体】，通过【视觉动作/记忆点】体现【具体商品事实】。使用【配色、材质和光线】，保证主体有明确轮廓、前后层级和 8%–10% 安全边距。画面绝不出现任何中文、英文、字母、数字、伪文字、乱码、LOGO、二维码、水印或模拟截图文字；所有页面和卡片均为无语义的抽象形状。缩小后仍能识别【商品身份】和主视觉主体，背景有商业设计完成度但不喧宾夺主。

## 五、负向提示词

负向提示词应针对当前商品，先写最可能造成误导或降低识别度的问题，再写通用画面问题。通常包含：

- 与商品身份不符的实体物、界面、服务流程或交付物；
- 伪造软件界面、课程后台、目录、收益截图、客户案例、评价、证书、奖章和官方背书；
- 未经证实的“月入、包过、100%、第一、全网最低、限时折扣、销量”等文字或视觉暗示；
- 过量文字、重复标题、错别字、乱码、伪文字、二维码、无关 LOGO、水印和站外联系方式；
- 紫色渐变套模板、廉价爆炸贴、过度霓虹、强光晕、复杂背景、主体过小、文字与主体重叠、低清晰度。

负向提示词不能代替正向构图指令。先说清楚要画什么、放在哪里、如何形成视觉重点，再排除不该出现的内容。

## 六、上图文字和叠字坐标

- 主标题优先采用“主题或商品名 + 商品身份”，不能只有“轻松搞定”“效率翻倍”等结果型口号。
- 辅助短语只表达一个真实内容、场景或价值；没有合适短语时留空。
- 不把自动发货、网盘、采集整理费和侵权反馈写成醒目主卖点。只有商品本身就是自动发货功能服务时，才按商品价值处理。
- `overlay_layers` 每项包含 `role`、`text`、`bbox_pct`、`align`、`max_lines`；`bbox_pct` 使用 `[x, y, width, height]`，单位是整张画布百分比。
- 坐标要给文字实际呼吸空间，不让主标题和主体抢同一块区域；所有文字框都应落在安全边距内。
- 含字版列出的文字与 `overlay_layers.text` 必须逐字一致，不能为了画面效果临时增删。

## 七、常见失败与改写方向

| 失败写法 | 具体问题 | 改写方向 |
| --- | --- | --- |
| “做一张高级、爆款、吸睛海报” | 没有商品对象、主钩子和构图 | 先指定商品身份、主体、版式和一个视觉记忆点 |
| “把商品文案都放上去” | 缩略图不可读，首图像说明书 | 只保留一个身份标题和一个可信短语 |
| “紫色渐变、发光、玻璃卡片、科技感” | 视觉模板化，商品类别不清楚 | 让商品内容或交付成果成为主体，用材质和结构制造吸引力 |
| “放几张软件截图” | 没有真实素材时会制造假证据 | 使用抽象模块示意，或由用户提供有权使用的真实截图 |
| “加上自动发货、秒发、永久保存” | 履约信息盖过商品价值，且可能无依据 | 留在商品说明；首图只展示商品价值 |
| “加入收入数字、销量和好评” | 形成无法证明的社会证明或结果承诺 | 改为真实内容、服务范围或交付成果 |

## 八、执行前自检

输出 prompt 前确认：

- 一张图只有一个主钩子、一个主视觉主体和一个主要版式骨架；
- 主标题在缩略图中可读，且明确商品类别；
- 画面吸引力来自具体主体、结构对比或材质层次，不是无关特效；
- 视觉中的每个重要对象都能回溯到商品文案或已核实事实；
- 无真实素材时没有伪造截图、目录、案例、证书和收益证明；
- 含字版与无字版的主体、构图、配色、文字区互相匹配；
- 上图文字没有带入交付、售后或侵权说明中的未确认承诺；
- `prompt_with_text`、`prompt_without_text` 和 `negative_prompt` 都是完整可执行的提示词，不写“见上文”。

## 九、与图片生成脚本的衔接

- 直接生图：使用 `prompt_with_text`；生成后必须检查中文、主体、裁切和实际商品对应关系。
- 分层生图：使用 `prompt_without_text` 生成背景，再按 `overlay_layers` 叠字；这是中文准确性更稳定的路线。
- 当前技能只负责提示词和方案，不宣称已完成真实图片验收。生成脚本还需要负责输出格式、文件存在性、尺寸一致性和失败处理。
- 不向图片模型承诺“100%准确”“一定提升点击率”等不可验证结果。
