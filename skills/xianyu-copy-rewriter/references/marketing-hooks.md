# 闲鱼文案营销钩子速查

这是**功能性分类**，不是营销学唯一标准。每款商品优先一个主要购买理由，再用少量相关信息支撑；不强凑钩子数量。具体内容或能力应与使用场景、买家利益相连，真实优先。

| 类型 | 买家心理 / 用途 | 适用表达示意 | 边界 |
|---|---|---|---|
| 1. 收益结果型 | 对结果、机会感兴趣 | “了解虚拟商品选品和运营方法” | 具体收益、成功率、收入增长需真实可证；不得暗示保赚 |
| 2. 痛点共鸣型 | 解决当前难题 | “想做AI漫剧，但不会画角色？” | 不捏造用户普遍痛苦 |
| 3. 低门槛型 | 怕难、怕学不会 | “从基础操作开始讲，新手也能跟着了解” | 不保证人人精通 |
| 4. 利益价值型 | 希望物有所值 | “教程与配套资料放在一起” | 内容范围要真实 |
| 5. 省时省力型 | 避免重复劳动 | “减少反复寻找零散教程的时间” | 不承诺未证实的效率数字 |
| 6. 数字量化型 | 信息具体清晰 | “含5个课程模块” | 数字须有依据 |
| 7. 价格价值型 | 在意购买成本 | “工具与教程打包” | 不虚构原价、折扣或收费规则 |
| 8. 好奇悬念型 | 想知道解决办法 | “不知道虚拟商品怎么上架？” | 不故弄玄虚和标题党 |
| 9. 稀缺紧迫型 | 担心错过 | “活动截止今晚” | 限时/库存必须真实可核实 |
| 10. 权威背书型 | 寻求专业可信 | “按实际操作步骤整理的教程” | 不虚构专家身份、官方授权 |
| 11. 社会认同型 | 借鉴他人选择 | “用户反馈” | 评价、销量、案例真实且经授权 |
| 12. 风险降低型 | 害怕买错 | “可先沟通适配情况，再决定购买” | 不虚构退款或售后承诺 |
| 13. 差异对比型 | 判断为何买它 | “把选品、上架、运营放进一套资料” | 不贬低竞品、不捏造优势 |
| 14. 人群场景型 | 判断是否适合自己 | “适合刚接触漫剧的创作者” | 不滥用“任何人都适用” |
| 15. 即时满足型（履约辅助） | 想尽快拿到 | “网盘交付/秒发” | 仅在确实可以兑现时使用；除非卖的是自动发货功能，否则只放在“商品说明”。 |

**运用口诀：** 核心搜索词 + 购买理由 + 自然口语。钩子可以是问题、场景、实际利益，不一定是夸张形容词。发现原文的强钩子时，不简单删除；先判断证据与兑现条件，再保留、优化或以真实卖点替代。

交付说明的适用范围和措辞以 [本店经营规则](../../../business/rules/xianyu-shop-operations.md) 为准。营销钩子不替代完整的商品说明，也不构成额外的服务或效果承诺。
