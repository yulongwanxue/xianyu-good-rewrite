# 闲鱼商品经营与说明规则

生效日期：2026-10-27。依据：经营者在本次需求中确认的经营方式。本文件是文案重写时经营说明的统一来源；修改经营方式时先更新此处。

## 1. 信息来源与适用范围

商品标题和描述由两类信息组合：原始材料中的商品事实，以及本店已确认的经营规则。不得把原卖家的承诺直接当成本店承诺。

| 信息 | 采用方式 |
| --- | --- |
| 商品是什么、包含内容、功能、规格、适用范围、使用依赖 | 从原始材料提取；用户针对本商品的事实更正优先。不能从商品名称推导未提供的功能 |
| 本店交付、费用性质、侵权反馈处理 | 使用本文件中适用的规则；本次用户明确指定的商品安排优先 |
| 原卖家的交付、退款、免费教学、安装、更新、个人经历、销量等 | 不自动继承；按性质列为来源说明、待确认安排或需证据主张 |
| 尚未确认的本店安排 | 不补成确定承诺；影响购买决定的事项放入独立的卖家审核备注 |

经营规则不能覆盖商品的重要使用条件，也不能改变实际交付物。原文与本店规则的差异若只涉及本店已确定的交付方式，可按本店方式改写；若涉及安装、激活、服务履约等关键条件，应记录冲突，不静默删除或替换。

## 2. 已确认的交付规则

- 本店可通过网盘交付的数字资料、教程、模板、素材、源码文件等，默认采用自动发货、网盘交付。
- 可使用的买家说明：**“本商品为电子版，通过网盘交付，拍下付款后自动发送领取信息。”** 根据商品实际形态调整“电子版”等措辞。
- “自动发货”只说明发送领取信息的方式，不等于保证秒到、全天候无故障、永久有效、永久免费补链或永久更新。
- 未指定具体网盘时只写“网盘”，不自行添加百度、夸克等品牌；不编造下载速度、保存期限、设备兼容或免会员条件。
- 该默认方式不适用于实体物流、账号开通、在线订阅、咨询、代做、部署等需要实际履约的商品。此类商品按本次已确认安排描述，不承诺付款后自动完成服务。
- 软件、源码的文件交付不等于安装、激活、部署或账号权限交付；文件可下载也不等于手机电脑都能运行。
- 放在描述末尾的“商品说明”中。若售卖的服务本身就是开通自动发货功能，则该功能属于商品价值，不能误归类为卖家发货方式。

## 3. 网络资料、收费性质与侵权反馈

### 适用条件

经营者确认的网络资料收集整理业务，可说明资料来自网络、费用主要对应采集与整理工作。只用于实际属于这类业务的商品；不能给原创作品、软件授权、独立开发或技术服务统一贴上“来源于网络”的说明。

### 可采用的买家说明

> 本商品为网络资料收集整理，费用主要对应资料采集、分类与整理。相关内容权利归原权利人所有。如权利人认为涉及侵权，请通过闲鱼私信联系并提供相关信息，核实后及时下架处理。

允许按商品压缩措辞；“采集整理费”是费用性质说明，不添加新收费项目，不改变商品价格，不宣称只收取某项费用或不存在其他使用成本。

### 使用边界

- “网络来源”“采集整理收费”“侵权联系下架”不构成销售或分发授权证明，也不消除侵权责任。
- 不生成“网络公开所以可售”“版权问题与本店无关”“购买后风险自负”“整理费所以不侵权”等免责结论。
- 已明确的来源署名、授权范围和用途限制应准确保留；原卖家自行声称的授权不自动成为本店已核实授权。
- 不凭空添加“正版授权”“可商用”“禁止转卖”“仅限个人学习”等权限结论。相关权限和限制应有具体来源。
- 不因附上声明就把明确未经授权、盗版或关键分发权限存疑的商品判为可用；这类事项独立记录给卖家审核，不以免责声明替代处理。
- 侵权反馈使用闲鱼私信，不自行添加站外联系方式。

## 4. 尚未确认的安排

目前未统一确定退款条件、售后范围、免费安装或教学、更新期限、补链期限、具体网盘、链接有效期、商用或再分发权限。

不得自行补上“一经发货不退不换”“终身更新”“包安装”“不会用免费教”“永久保存”等条款。对本商品确有购买影响的缺失信息，在卖家审核备注中列出；不要把“待商家补充”放进买家文案，也不要每条商品机械列全套未知事项。

## 5. 买家说明与卖家备注

- 买家可见描述：商品价值与范围在前，适用的交付、使用条件、费用性质、版权说明在后；重要门槛应紧邻对应功能，不能只藏在末尾。
- 卖家审核备注：与买家文案分开，承载来源冲突、未经确认的服务承诺、影响使用的缺失信息和权利疑问。不能随描述导入买家可见字段。
- 信息明确、可自动交付的资料商品，不默认要求买家先私聊。需确认环境、需求或服务范围的商品，才引导拍前沟通。
